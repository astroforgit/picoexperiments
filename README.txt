PICO8 Awesome Set 
v1.0 (apr-22-2021)

~~~~~~~~~~~~~ CONTENTS ~~~~~~~~~~~~~
This set is an curated extract of the PICO8 BBS full content, will all cartridges of interest organized by genres, excluding :
- school / learning projects
- demos
- WIP / unfinished games 
- single track musical carts
- some unpolished games (no sound at all, etc)
- programmation tutorials, technical carts

For each game you can find a txt file in the manuals subfolders containing :
- a copy of the text content of the page at the time of extraction
- the url to the cart page on the BBS
- for some games, some additional images with rules informations

~~~~~~~~~~~~~ LAST UPDATE ~~~~~~~~~~~~~
This set has last been updated on apr-21-2021, if you wish to update it yourself, use the following link.
https://www.lexaloffle.com/bbs/?cat=7&carts_tab=1&#sub=2

And go through the first pages until you arrive to the last cart with apr-22-2021 update date (keep only the carts actually updated with a higher date, 
as just adding a commment to a cart will push it on the first pages)

~~~~~~~~~~~~~ ITCH.IO ~~~~~~~~~~~~~
Most pico8 games on itch.io (ven the free ones) seems to not be published on the BBS, the most notorious beeing Poom, but only as standdalone windows or linux version.
Some games propose p8 versions, but I'm unsure if this is compatible with pico8 emulators.
So there is no way to include them in this set easily or I don't know how.

Anyway I managed to write a custom scrapper extracting the games list with their name, price and url
So you'll find two extra txt files included :
- a full list of all itch.io games with the tag pico8
- a list of all pico8 itch.io games not in the set (based on name comparison)


Enjoy!
