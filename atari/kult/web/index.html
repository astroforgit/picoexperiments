Arrow keys / WASD: move · Ctrl: change weapon · Shift: bomb · Space: one-second shield · Z / X / C: three-second one-third-speed clock · P / Escape: pause.

Carry up to three bombs, shields and clocks. Common clock pickups slow enemy projectiles, enemies and meteors; your ship and its shots keep their normal speed. Indestructible meteors. Skull sub-bosses release three rewards.

About this simulator

Uses the current Atari game's selected animated ship, enemy sprites, wave records, movement paths, drop tables and bottom-panel artwork. No fuel, top panel, planets or wave minimap. Browser combat timing, collision, score and synthesized sounds are approximations; it is not an Atari emulator. Sector-end guardians use their recovered original artwork; original POKEY music is not reproduced.

Edit waves in the flight workshop. “Play draft in browser game” previews unsaved changes; applying a project updates the default browser game on reload.
