About this browser reconstruction

Built from the supplied CETAS WIP disk: original title artwork, 44 sprite records, the spawn script and translated movement tables. This is a playable JavaScript adaptation, not an Atari emulator. Timing, collision placement, health, scoring, lives, pulses, enemy firing, palette and synthesized sound effects are adapted. The original POKEY music and menus are not reproduced.

The game runs locally with no external downloads or accounts. Your best score is saved in this browser. Read the implementation notes ↗
