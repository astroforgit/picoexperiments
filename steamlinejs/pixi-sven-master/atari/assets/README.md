# Milestone artwork

`enemies-atlas.png` was created with the built-in imagegen tool for this port.
It is new adaptation artwork, not extracted original Sven artwork. The build
cuts the 4×4 sheet into two walking poses and four directions for each enemy,
preserves alpha, and downsamples into the shared VBXE palette.

Final generation prompt:

Use case: illustration-story. Asset type: one production game sprite atlas for an Atari VBXE cartoon meadow arcade game inspired by early-2000s hand-drawn PC games. Create a genuinely transparent PNG sprite sheet, exactly 4 columns by 4 rows in a square canvas, sixteen equally spaced cells with generous transparent gutters, no text or grid lines. All actors are viewed slightly from above with chunky dark outlines, simple flat warm colors, crisp readable silhouettes. Row 1: the same shaggy brown sheepdog, four orientations in order facing down toward viewer, up away from viewer, left, right. Row 2: same four dog orientations with an alternate walking leg pose. Row 3: the same elderly stocky shepherd with large white beard, green coat, red trousers, brown boots and wooden crook, in order facing down, up, left, right. Row 4: same four shepherd orientations with alternate walking leg pose. Center every actor within its own equal cell and align feet at a consistent baseline; complete bodies and crooks with no clipping or overlap. Dog is friendly-looking but alert, on four legs; shepherd looks grumpy and comical. Consistent identity and scale across poses of each actor, strong dark outline, no shadows outside the sprite, no scenery, no letters, no watermark. This will be downsampled to small 56x32 sprites so avoid fine texture.
