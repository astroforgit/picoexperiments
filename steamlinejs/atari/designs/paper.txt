# Bimbaj board design, read by generate_tiles.js. Colours are Atari palette
# values: background = COLBK (pixel 0), floor = COLPF0 (pixel 1, one value per
# character row of a tile), light = COLPF1 (pixel 2, also the status text),
# blue / copper = COLPF2 / COLPF3 (pixel 3; the tile picks one), status =
# the status bar. elephant maps the shared elephant art's outline, wrinkle,
# highlight and body colours onto this design's pixel values.
# Each tile is 12x24 native ANTIC 4 pixels (one character is 2:1 wide);
# '.' shows the floor tile through. Arrows down/left mirror up/right.
